PROPOSAL (NOT SENT TO DEVELOPER) - Discovery tab redesign for the next beta
2026-10-19. Written by AUDITOR from the owner's request and the screenshots. Nothing goes to DEVELOPER until the owner accepts.
Based on reading src/renderer/src/screens/DiscoveryTab.tsx (1,272 lines), Dashboard.tsx (LiveCard/LiveAccountTile), components/ChatExtras.tsx (ChatStatusLine), lib/chatStatus.ts, styles/global.css.

1. LIVE FEED = A VERTICAL VERSION OF THE DASHBOARD'S LIVE VIEW (same behavior, less messy)
Today (DiscoveryTab.tsx 431-498): a plain list of rows (thumb, name, "Looking into it...", "Worth about $X, N min ago"), plus an "Ask Clynx" row. The Dashboard's Live view (Dashboard.tsx LiveCard 405-476 + LiveAccountTile) is a stack of live tiles: what it is doing right now, the photo it is on, its reaction.
Proposed:
 a. Keep the left column, same width (about 300-360 px), same data and same click behavior (click a row = open that product in the main window; "Ask Clynx" stays on top).
 b. Restyle the column as a vertical stack of the same tile design the Dashboard uses: photo thumbnail on top or left, name, one status line, a small status chip (Researching / Worth flipping / Not great / Can't judge / Didn't work out), time ago. One consistent card height; no mixed emoji thumbnails (use the product photo, else the Clynx logo as placeholder).
 c. "Researching" entries get the live tile treatment (current action + the same animated dot used on the Dashboard); finished entries collapse to one compact line so the column stays calm.
 d. Header "Live feed" stays, with "N researching" / "idle" as today.
 e. Pure layout/style change: no change to how entries are created, ordered or stored.

2. ONE WINDOW INSTEAD OF TWO, Claude-style
Today (DiscoveryTab.tsx 543-654): two cards side by side (Automation | Chat with Clynx), or two tabs when narrow.
Proposed:
 a. One main window. Header with a switch: [Everything] [Automation] [My chat]. Default "Everything" = one chronological stream like Claude: your messages, Clynx's replies and its automatic findings in order. "Automation" = only what Clynx found on its own (keeps the existing All / Worth flipping / Not great / Researching filters). "My chat" = only your conversation.
 b. Composer pinned at the bottom in every view (as in Claude): attach button, text box, Send. The three starter chips show only on an empty chat.
 c. Messages look like Claude: your message as a rounded bubble on the right labelled "You"; Clynx's reply as plain readable text on the left under the Clynx logo (no heavy card), generous spacing, a "Jump to latest" button as today.
 d. Product cards from Automation (verdicts, "Ask about this", "Open in Library") stay as cards inside the stream.
 e. The existing narrow-window tab code and the unread dots go away (replaced by the switch).

3. CLYNX'S NARRATED THINKING (images, pages, thought process)
Today: chat shows one line "Researching eBay... 8s" and an optional collapsed "Web activity (N)" list of text labels; the Automation side shows short "thoughts" (text only). No images or page links are in these events.
Proposed (like Claude's thinking panel, collapsed by default, one per Clynx turn):
 a. A collapsible "Clynx's thinking" block above the reply, open while it works, collapses to "Thought for 12s - looked at 3 pages, 5 photos" when done.
 b. Inside, in order: short first-person thought lines ("Checking whether this is the console or the game..."), each page it opened (favicon + title + domain, click to open), each photo it looked at (small thumbnail, click to enlarge), and any worry or decision ("These two photos disagree, so I'm leaving it out").
 c. The same block feeds the Live feed tile of the product being researched (latest line + thumbnail).
 NEEDS NEW DATA (this is the one part that is not purely visual): the main process currently sends step labels only. DEVELOPER must add fields to the status/thought events: kind = "thought" | "page" | "image", plus url, title, thumbnail (a small data URI or a local file path), and emit them from the places that already know them (web research, photo checks, comp reads). Keep it small: thumbnails capped (for example 160 px), at most about 20 items per turn, no personal data, nothing stored longer than the chat history.

 b. Stop box: make it a real coloured button (accent colour, rounded, white square icon + "Stop"), same size as Send, visible only while it runs. Today it is a plain ghost button "[square] Stop" (ChatExtras.tsx 37-41).
