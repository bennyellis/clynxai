FIX (generic; no product, brand or edition is named anywhere)
 webEvidence.ts (new): three search backends tried in turn (DuckDuckGo HTML, DuckDuckGo Lite, Bing) with real markup parsers; a bot check/refusal is recognized and
   recorded as BLOCKED, a backend that blocked or failed is left alone for 10 / 1 minutes, searches are spaced; page text now includes the title, meta tags, JSON-LD,
   JSON in scripts and image/aria labels; a page that a plain request cannot use is rendered once in a separate throw-away Chrome/Edge (never the Facebook window)
   and its text read; every search and page read is traced (backend, outcome, HTTP status, characters, plain or browser).
 searchLinks.ts: a pasted Google/Bing/eBay/Walmart results link is recognised as a search, not a page; its query is used as a search and the answer says plainly that
   it was not read as a page. A link that cannot be read is listed as unreadable and Clynx is told not to claim it opened it.
 variantEvidence.ts: matching requires the claim's words near each other (a console and a game on the same page do not make a product); the evidence's own name for
   the product is captured ("Xbox Series X - 2TB Galaxy Black Special Edition" for "Galaxy Edition") and a verified variant is filed under that name; if every search
   was blocked or failed the verdict says the lookup failed ("says nothing about whether the product exists"), never "nothing found".
 variantIdentity.ts: alternate names (the edition word tried with Special / Limited, a themed name given one), maker's site searched first.
 variantResearch.ts / chat prompts: the answer to Clynx now carries a factual summary of what happened (searches by outcome, pages read), the unreadable/search links and the
   blocked-search instruction, replacing the template wording.
 scripts/variant-live-check.cjs: runs the real verification against the live web and prints every search, page, classification and verdict. On your PC:
     node scripts/variant-live-check.cjs                       (the two Xbox claims from the report plus "Galaxy")
     node scripts/variant-live-check.cjs "Some Product" --url https://...     (any claim, optional link)
   Run in this sandbox it correctly reports every backend unreachable ("search blocked/unavailable"), not "nothing found".

FIRST LIVE RUN (user's PC, 2026-10-15) - REAL-WORLD RESULT

 EXACT RUNTIME FAILURE of the build that returned UNVERIFIED: on that PC both DuckDuckGo endpoints fail at the connection level ("fetch failed" for the HTML and the Lite
   endpoint, every query). The old code searched through DuckDuckGo only, so every search errored, came back empty and ended as "UNVERIFIED". Bing answered every query
   (6 results each) and the manufacturer and retailer pages were fetched as plain HTML (200, 2k-50k characters) with no browser needed. So it was neither a bot check nor
   JavaScript-only pages here: it was a single search backend that could not be reached. The multi-backend search is the fix; a rebuilt installer is required.
 Found in that output and fixed afterwards: the extracted "official name" was junk for two claims ("An XBOX Series X Galaxy and an adaptive joystick controller." is an
   image caption; "Buy Halo Infinite XBOX Series X" is a button on the game's page), and the verified variant would have been filed under it. Names are now scored
   (a caption, a button or a sentence scores below zero and is never used; a title with an edition word scores higher), the best-reading name across all sources wins
   ("Microsoft Xbox Series X Halo Infinite Limited Edition"), and the entry is renamed only to a name that reads as a product title. Connection errors now show their
   cause code in the trace. Regression checks use the real strings from this run.
 Remaining weakness the run exposed: the xbox.com page for the Halo Infinite GAME mentions "Xbox Series X", so a manufacturer page about a game can count as a full match
   for a console edition; here the retailers independently list the edition, but a claim supported only by a game page would be over-credited. The verdict also
   does not yet tell a console from a game or accessory of the same name.
