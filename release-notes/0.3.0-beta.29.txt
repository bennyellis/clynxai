Clynx Beta 29 - a rebuilt Discovery window, versions and add-ons found from sources, safer chat
Read this first: most of this beta is new screens and new background work that was tested with fakes and by code review, and has not been run end to end against the real services. If something looks wrong, tell us what you saw.
What changed
* Discovery is one window. A switch at the top picks Everything (your messages, Clynx's replies and what it finds on its own, in the order it happened), Automation (only what it found on its own, with the Worth flipping / Not great / Researching filters) or My chat. The box stays at the bottom in every view. Your messages are rounded bubbles under "You"; Clynx's replies are plain text beside its logo. A reply that is still being written stays at the bottom, and "Clynx is answering..." with a Stop button shows in every view.
* The Live feed on the left is a stack of live tiles: a product being researched is a full tile (photo or the Clynx logo, a pulsing dot, its latest thought); a finished one is one line with a verdict chip.
* Clynx's thinking is shown above each reply: short first-person lines, the pages it read (click to open in your browser) and small thumbnails of the photos you sent (click to enlarge). It is open while Clynx works and folds to one line, "Thought for 12s - looked at 3 pages, 1 photo". These are real events the app recorded, not the AI's hidden reasoning; at most 20 items a turn, addresses are cut to the page (no query strings or credentials).
* Chat: one set of typing dots after "Thinking", Stop is a coloured button that stays while a reply streams, the Clynx logo and the word "You" replace the grey letters. A greeting or a plain question can no longer start the scanner, write a note or change anything; Clynx no longer opens a reply with "Done" when nothing was done, and no longer shows internal tool names. The "I read X as Y" line for a repaired spelling is now shown by the app itself.
* Versions and add-ons are found from sources and kept in a queue. After a first research Clynx asks eBay's listings (storage, colour and edition values real listings use), then web catalogues, with the AI's memory only as a hint, and checks the names a few at a time in the background (never while a research is running or while you are using Clynx). A version that only ONE source names stays a suggestion on the product page; it becomes a Database entry when a second source or a listing confirms it. Add-ons named by a source (a maker's page, or a bundle listing the scanner saw) get their own accessory entry, filed by the same categoriser as everything else, and never price a console (and a console never prices them). A "Versions and add-ons Clynx found" list on each product shows every name with its status. Failed checks wait and retry, then are set aside with a note.
* Price research no longer fails as a whole when the sold-price lookup (the WatchCount browser) fails or hangs: it is cut off after two minutes and Clynx goes by the asking prices it found.
* OpenAI searches have no hourly limit by default (a number in config.json still sets one).
* A new, standalone sold-comps module (providers for your own imported sales, WatchCount and eBay's Marketplace Insights once approved, its own tables, identity matching, a command-line harness) is in the code but is NOT connected to anything yet.
What is NOT fixed or not proven
* None of the screens above has been looked at on a real screen by the people who built them: spacing, alignment and the new window layout may need adjusting. The thinking block, the Live feed tiles, the variants/add-ons worker and the eBay "item specifics" request (built to eBay's documented format, never seen working) are the least proven.
* The background worker uses AI and web searches (unlimited by your settings) for every product's versions and add-ons; if credits matter, watch the first few researches.
* Known gaps: typed names can still create a duplicate in some cases; a new generation (Canon R6 Mark II) can be filed under the older model; the question check is rough in both directions; a product's page can open scrolled down; the Library chat's avatar is 2 px narrower than the "You" label there; the console thumbnail for some entries is still game box art; items from background photo/price checks are not shown in the thinking block; the thinking block does not feed the Live feed tile yet.
* Versions and add-ons are not synced between two signed-in computers: each runs its own queue and can create the same entry before sync catches up.
* Clear all and Reset with cloud delete your server's copies too when you are signed in. Nothing in your library is changed by installing this update.
