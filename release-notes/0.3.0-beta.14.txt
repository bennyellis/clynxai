Clynx Beta 14 - Clynx researches what it is unsure about
* New: when Clynx is not sure which version of a product a listing is (for example a Meta Quest 3 in 128GB or 512GB, or a look-alike Quest 3S), it now researches the product line on the web itself. It types the searches a person would ("meta quest 3 128gb vs 512gb difference"), reads what comes back, and remembers the storage sizes the line really comes in and the look-alike models that are different products. A fact is kept only if two sources, or the maker's or a retailer's page, say it.
* New: you can ask any chat to do it ("how do the Quest 3 versions differ?"). Each lookup shows in Activity > AI Activity under "Researched a product on the web", with the searches it ran and which search engine answered.
* New: an optional official search route. Set BRAVE_SEARCH_API_KEY in your .env file (see .env.example) for steadier results; the free engines (DuckDuckGo, Bing) still work with no key. If you already have a Google Programmable Search whole-web engine, GOOGLE_CSE_API_KEY and GOOGLE_CSE_ID still work and are tried first (Google no longer offers this to new accounts and ends it on 2027-01-01). Keys are never shown or logged.
* Safe by default: learned facts only ever make Clynx MORE careful (a "Quest 3S" listing is no longer priced as a "Quest 3"). In this build it runs in shadow mode: it researches and records what it WOULD reject, but changes no price, alert or photo. Switch the effect on with config.json "beta13": {"webKnowledge": "enforce"} after you have checked AI Activity; "off" disables it. At most 4 researches an hour, each remembered for 45 days.
* Unchanged: everything in Beta 13, your data, sign-in, updates, and the seller, scam and placeholder-price rules.
