Clynx Beta 28 - caption-name fix, no hourly OpenAI search limit, tidier chat
What changed
* A picture caption is no longer taken as a product's official name. In the Beta 27 live test the Galaxy edition was renamed "Back panel of XBOX Series X 2TB Galaxy Black Special Edition". A verified official name must now open with the same word as the name you typed, and anything describing a photo or a part ("photo of", "front view", "see more", "buy") is refused; when in doubt your typed name stays. If Beta 27 already renamed an entry, rename it by hand: this update does not repair it.
* OpenAI searches have no hourly limit by default (they were 12 an hour for hard research and 20 an hour for ordinary look-ups). A number in config.json (openaiSearchPerHour, openaiLookupPerHour) still sets one. The 1.5-second spacing, two-at-a-time cap and the 7-day memory of repeated questions stay, and so do Save-credits mode and the server's own limits. This means a first look-up of a new product spends credits every time it runs; nothing yet cuts the number of searches it makes.
* Chat tidy-up, first step: one set of typing dots after the word "Thinking" (there were two), Stop is now a coloured button, the Clynx logo replaces the grey "C", and the word "You" replaces the "Y" circle, in Discovery, the Live/Activity chat, the Library chat and the floating chat.
What is NOT fixed or not proven
* The chat changes were checked in code and with a build on a scratch profile only by reading; they have not been judged on the real screen yet, and the layout may need adjusting.
* Everything listed as not proven in Beta 27 still applies: OpenAI web search through your own server end to end, the automatic retries, the Galaxy parent link, the cloud-delete behaviour against a real server, and the "I read ... as ..." line, which the chat does not reliably show.
* Known and unfixed: typed names can still create a duplicate ("dewalt dcd771" next to "DeWalt DCD771C2 20V Drill"); a new generation (Canon EOS R6 Mark II) can be filed under the older model; a short attribute after a full stop ("iPhone 15 Pro Max. 256GB. Blue") is treated as a request; the question check is rough in both directions; a 401 from OpenAI still schedules automatic retries; "find me" alone becomes a product called "me".
* Clear all and Reset with cloud delete your server's copies too when you are signed in. Nothing in your library is changed by installing this update.
* Not built yet: the Live feed redesign, one combined Discovery window, Clynx's narrated thinking (pages and photos), and the rest of Add-ons.
