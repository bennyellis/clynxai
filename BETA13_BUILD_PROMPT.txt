## DECISIONS ALREADY MADE (the report's open questions, answered with its recommendations)
- Quarantined / needs-review photos stay visible in the gallery, dimmed with a "Needs review" badge; they are excluded from reference use.
- Colour is value-defining only when tied to an edition/configuration (Galaxy Black SE, Robot White All-Digital, Halo LE, named limited
  editions) or when the product's own name states it; otherwise cosmetic (gallery scope "any colour").
- A one-time NON-destructive suspect pass on existing galleries is approved (marks status 'needs_review', excludes from reference use,
  deletes nothing). Untitled images stay 'legacy' (still eligible).
- Folders are local-only in Beta 13 (no cloud migration); upsertProductFromCloud must never touch folder_id or other new local columns.
- Condition: dedicated visual pass only for listings that already clear text+price pre-qualification; adjustment table is hand-seeded,
  editable in config, shown as an assumption; prefer defect-matched sold comps when >= 3 exist. Ships SHADOW first.
- Trash retention 30 days, covers products, images, folders.
- Choice buttons: max 6 options; keep plain-text fallback if the model does not call ask_choice.
- Chat brevity: 1-3 sentences, max_completion_tokens ~350 for chat (opt-out when the user asks for detail). Send verbosity:"low" only if
  a test shows the route accepts it; otherwise rely on prompt + token cap + post-guard.
- Phase 4 safeguard (identity/*): leave code, default mode stays "off"; fold its useful resolver into the new model only where trivial.
- Identity decisions store a 120 px thumbnail in AI Activity (like Beta 12 decisions). Chat attachments are never stored there.
